# tapty.

Объявления по Казахстану: сайт и приложение (PWA). HTML, CSS, JavaScript без фреймворков, Cloudflare Workers и D1.

## Что есть

- Главная с товарами по два в ряд, категории, выбор города в фильтрах
- Поиск и фильтры: цена, состояние, торг/обмен/даром, сортировка
- Подача объявления с фото (до 6, сжимаются в телефоне), черновик
- «Заполнить по фото»: нейросеть предлагает категорию, заголовок и описание
- Аккаунты по логину и паролю: без аккаунта можно смотреть, искать и звонить; с аккаунтом — лайкать, подавать объявления, писать продавцам и оставлять отзывы
- Страница товара: все фото (на весь экран с увеличением), характеристики, карта (Яндекс Карты) и ссылка в 2ГИС, номер объявления и просмотры, номер по нажатию, звонок, WhatsApp, Telegram, «предложить цену», сообщение продавцу, похожие объявления
- Чат между покупателем и продавцом с фото, отметкой о прочтении и числом непрочитанных
- Блокировка собеседника и жалоба из чата
- Закрепление и удаление чата
- Смена пароля и восстановление по резервному коду
- Подсказка цены при подаче по похожим объявлениям
- Если цену снизили, прежняя показывается зачёркнутой
- «Такие же товары по другой цене»: тот же товар у других продавцов
- Районы Астаны и Алматы: выбор в объявлении и фильтр
- Страница продавца: все его объявления, отзывы, значок «Проверенный продавец» (от 3 отзывов, средняя оценка от 4,5)
- Избранное, «мои объявления»: продано, изменить, продлить, удалить
- Жалобы, отзывы и страница модерации `/admin`
- Русский и казахский языки, установка на телефон, работа без интернета для уже открытого

## Запуск на Cloudflare

1. Cloudflare → Workers & Pages → Create → Import a repository → `gdev49df/Tapty`.
2. Имя воркера — `tapty`, команда деплоя — `npx wrangler deploy`, команда сборки пустая.
3. Нажмите Deploy. База D1 `tapty` уже создана и указана в `wrangler.jsonc`, таблицы появятся сами.

После этого каждый push в `main` выкатывается автоматически.

## Секреты (Settings → Variables and Secrets, тип Secret)

| Имя | Зачем |
|---|---|
| `ADMIN_KEY` | Длинный пароль для страницы `/admin`. Без него модерация выключена. |

Секреты `BOT_TOKEN` и вход через Telegram больше не используются.

## Аккаунты, чат и отзывы

- Пароль не уходит из браузера: из него считается ключ (PBKDF2), сервер хранит солёный хеш ключа.
- Почта и телефон при регистрации не спрашиваются. Забытый пароль меняется по резервному коду: он показывается один раз после регистрации, новый можно получить в профиле. Без кода и пароля аккаунт не вернуть.
- Фото из чата не открываются по прямой ссылке: сервер отдаёт их только двум участникам диалога. Не больше 40 снимков в сутки с аккаунта.
- Блокировка закрывает переписку в обе стороны. Номер телефона в объявлении остаётся виден.
- «Удалить чат» убирает переписку только у того, кто удалил: собеседник и модератор по жалобе видят её по-прежнему. Новое сообщение возвращает чат в список, но без старых.
- Жалобу разбирает модератор на `/admin`: он видит переписку, на которую пожаловались.
- Объявления, поданные с устройства без аккаунта, переезжают в аккаунт при регистрации или входе.
- Избранное хранится в аккаунте и видно на всех устройствах. Отметки, сделанные на устройстве раньше, переносятся при первом входе.
- Гость видит номер и может позвонить; ссылки WhatsApp и Telegram сервер отдаёт только вошедшим.
- Новые сообщения подтягиваются опросом (в открытом чате раз в 4 секунды). Уведомлений на телефон нет.
- Отзыв можно оставить после переписки, где писали обе стороны. От накрутки вторым аккаунтом это полностью не защищает.
- Новые столбцы и таблицы в базе создаются сами после деплоя.

## Полоса про соцсети

Над всеми страницами, кроме переписки и модерации. Адреса задаются в `SOCIALS` в `public/js/promo.js`; пока они пустые, полосы нет.

## Фото

Сейчас фото хранятся в D1. На бесплатном тарифе одна база вмещает 500 МБ, это несколько сотен объявлений с фото.
Чтобы перейти на R2: включите R2 в Cloudflare, создайте бакет `tapty-photos`, раскомментируйте `r2_buckets`
в `wrangler.jsonc`. Новые фото пойдут в R2, старые продолжат открываться.

## Заполнение по фото

Работает на Cloudflare Workers AI (модель `@cf/google/gemma-4-26b-a4b-it`), отдельный ключ не нужен:
привязка `ai` уже есть в `wrangler.jsonc`. На модель уходит только уменьшенное первое фото.
Заполняются только пустые поля, цену и контакты человек вводит сам.

Лимиты в сутки: 15 на человека, 40 на IP, 300 на весь сайт. Они берегут бесплатную квоту Workers AI,
меняются в начале `src/ai.js`. Если кнопка не срабатывает, причина последнего сбоя лежит в базе:
`SELECT value FROM meta WHERE key = 'ai_error'`.
